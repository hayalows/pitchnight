# Prop Studio fonts

Self-hosted Latin subsets used by `props.html` and embedded into exported prop images, so the
props render in the right typefaces on phones and in downloaded files.

- `anton-props.woff2`: Anton by Vernon Adams, SIL Open Font License 1.1 (https://openfontlicense.org)
- `space-grotesk-props.woff2`: Space Grotesk by Florian Karsten, SIL Open Font License 1.1

Subset to Basic Latin plus a few punctuation marks and arrows with fontTools `pyftsubset`.
